## Cara menjalankan

1. Clone repository:
   ```
   git clone https://github.com/LeoooSKenndyyy/JAPA-PRABU-ADVERTISING.git
   ```
2. Buka file `index.html` di browser.

## Tahapan pengerjaan

1. Membuat repository di GitHub dan mengaturnya menjadi Public.
2. Membuat file `index.html` berisi halaman tentang teknologi.
3. Mengunggah file ke GitHub:
   ```
   git add .
   git commit -m "tambah website"
   git branch -M main
   git push -u origin main
   ```
4. Mengaktifkan GitHub Pages lewat **Settings > Pages**, dengan sumber branch `main` dan folder `/ (root)`.
